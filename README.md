# 教室 CO₂ 预测与实验系统

基于 ESP32-S3、SCD41 和触摸屏的 CO₂ 采集、TinyML 预测与实验原型。

## 文档

| 文档 | 内容 |
|---|---|
| [操作说明](docs/Instruction.md) | 接线、编译上传、触摸校准、记录与导出 |
| [系统说明](docs/System.md) | 模块职责、数据流、存储和硬件集成 |
| [模型说明](docs/Model.md) | 数据来源、训练流程、TinyML 模型和评估 |

## 架构

```text
firmware/                  ESP32-S3 固件、界面、传感器和模型资产
model/                     训练、推理和实验脚本及模型产物
data/                      数据集与来源说明
docs/                      操作、系统和模型文档
tools/                     固件构建、数据导出和检查工具
```

## 当前状态

固件默认使用 SCD41 实时采集，模型输入为连续 CO₂ 分钟数据，预测结果在触摸屏上显示。模型、数据和实验记录分别保存在对应目录中。

当前源码 v1.12.1 已针对 USB 导出早退增加有界等待与短写续传，尚未上传设备或完成长记录实机验收。2026-10-13 存储镜像中的 14 场、19,588 条记录已通过离线完整性核验。审查结论与修复边界见 [系统说明](docs/System.md#v1121-usb-导出处理)。
