# 模型 Model

## 当前模型

输入为连续 20 个有效分钟的 CO₂，按最旧到最新排列；温湿度保留为观测数据，不参与当前模型。输出为末历史分钟 t 的 t+5、t+15 CO₂ 单点浓度，不是未来区间平均值。

网络为 20→32→16→2，隐藏层 ReLU、输出层线性，共 1,234 参数。训练目标为未来浓度相对当前值的增量，输出后还原 ppm。float TFLite 6,684 字节，int8 TFLite 3,496 字节，图中为三个 FULLY_CONNECTED 算子；固件预留 16 KiB 张量区。

当前模型 SHA256：`12aafb9717b430f24806ff4df01e2304d1802ec5f7ab6d131f463860dc44454b`。v1.11.2 保持训练权重不变，扩大输入量化覆盖；模型与 `firmware/model_assets.h` 必须同版，更换后重新编译上传。历史板端时延不能直接用于新模型。

`model/config.json` 的 `quantization_bounds.co2_ppm` 配置为 350～5,000 ppm。int8 输入刻度约 18.24 ppm，编码中心约 342.39～4,992.38 ppm，四舍五入后的接受边界约 333.27～5,001.50 ppm。20 个历史 CO₂ 均值必须全部可编码；温湿度不参与模型量化范围检查。覆盖扩大只表示能够输入，超过训练浓度范围的准确度尚未验证。

产物中的 config.json 与 metadata.configuration 是训练快照，不是新的第二套入口配置。重新训练前保存旧模型和评估结果，不能覆盖后仍将历史结果当作当前模型结果。

## 数据来源与防泄漏

当前使用 [UCI Occupancy Detection](https://archive.ics.uci.edu/dataset/357/occupancy+detection) 的公开办公室实测数据，Luis Candanedo，2016，CC BY 4.0。详细来源见 [数据说明](../data/uci/SOURCE.md)。这不是本教室或通风箱实测。

原始共 20,560 条，保留 CO₂、温度、湿度；当前输入仅取 CO₂，光照、人数占用标签及未来信息不作为输入。归档按配置 SHA256 校验；6,398 条时间需在一秒容差内对齐到整分钟，时间轴有 2,181 个缺失分钟，不插值。

先按完整日期划分，再分别建立窗口。每窗要求 20 历史 + 15 未来共 35 个连续有效分钟；不跨缺失、设备或场次。

| 集合 | 日期 | 原始记录 | 有效窗口 |
|---|---|---:|---:|
| 训练 | 2015-02-02 至 02-11 | 11,360 | 11,258 |
| 验证 | 2015-02-12 至 02-14 | 4,320 | 4,286 |
| 测试 | 2015-02-15 至 02-18 | 4,880 | 4,846 |

标准化和 551 条代表性量化校准窗口仅来自训练集；量化另加入 4 条配置范围锚点（350/5,000 ppm 恒值与上升/下降序列），仅用于校准，不参与训练或作为实测标签。Adam、MSE、L2 和验证早停；种子 42，最多 180 轮，实际 26 轮，恢复最佳验证第 6 轮权重。测试不参与选轮次。

## 评估结果

v1.11.2 可用测试子集：4,846/4,846 窗口，没有输入越界，量化可用比例 100%。该比例不等于教室实际采集可用率。

| 方法 | +5 分钟 MAE（ppm） | +15 分钟 MAE（ppm） |
|---|---:|---:|
| 持续性（当前值保持） | 15.46 | 26.50 |
| 岭线性回归 | 17.70 | 31.16 |
| float MLP | 18.03 | 32.80 |
| int8 MLP | 18.06 | 32.95 |

与原 4,804 条有效窗口在同一子集比较，扩大前后 int8 MAE：+5 分钟 16.93→16.94 ppm，+15 分钟 31.13→31.28 ppm。上表因新增了原本越界的 42 条窗口，不能直接与旧表比较。

当前网络尚未超过持续性基线，只能证明模型链路可运行，不能宣称教室预测优势。全部完整窗口及同一可用子集分别保存在 [metrics.json](../model/artifacts/co2/metrics.json)；MAE、RMSE、偏差、95% 绝对误差和阈值统计见 [报告](../model/artifacts/co2/REPORT.md)。输入饱和诊断样本不能当成有效在线预测。

## 训练与本地推理

在项目根目录执行。新建环境才需要安装依赖；现有 .venv 可直接使用。

```powershell
python -m venv .venv
& ./.venv/Scripts/python.exe -m pip install -r model/requirements.lock.txt
& ./.venv/Scripts/python.exe model/train.py
& ./.venv/Scripts/python.exe model/predict.py --csv model/artifacts/co2/example_history.csv
```

自采数据整理成每分钟一条、当地无时区时间后训练：

```powershell
& ./.venv/Scripts/python.exe model/train.py --csv classroom-minute.csv
```

`--export-only` 仅在数据哈希与训练配置完全一致时复用权重；不重新训练不能更换特征、窗口或数据。重新训练会更新 `model/artifacts/co2/` 和 `firmware/model_assets.h`；回放检查资产需要另外运行 `model/export_replay.py`。

只调整 `quantization_bounds` 时使用 `model/train.py --requantize`；该模式仍核对原数据哈希和其他训练配置，复用网络权重后重新量化与评估。旧部署包保存在 `.build/quantization-before-v1.11.2/co2/`。独立 rapid-rise 实验不继承当前模型的量化范围，保持原实验配置。

## 原始数据与预测评估

USB 导出是约 5 秒读数、事件和预测快照的混合记录，不能直接交给一分钟训练入口。先按 device_id、session_id、environment 分组，再按 record_type 区分测量、故障与预测。

- 原始记录全部保留；清洗过程另存结果，不回写原始文件。
- 有校时的导出日期带时区，训练前统一为采集地点无时区时间；未校时日期为空，需用可靠外部锚点恢复真实日期，不能猜测断电间隔。
- 每分钟汇总有效测量；故障、断档和样本不足分钟标记无效，不补造值。
- 训练目标只取未来实测 CO₂，不能使用预测字段或风扇模拟值作标签。
- 回放来源 `public_office_replay` 默认拒绝作为自采数据；仅流程检查可用 --allow-replay，仍需满足日期和窗口条件。

格式 4 的 measurement 列为 `prediction_5_ppm`、`prediction_15_ppm`；旧格式 1–3 为 +15/+30，导出器按版本映射。独立 `prediction_snapshot` 保存末历史分钟、目标分钟、发布运行时间、预测状态、模型哈希及情景假设。

v1.12.0 为格式 4 增加预测状态 5（主动关闭），原状态 0–4 含义不变；关闭时预测值为空，原始测量仍保存。正常分钟结算发布一次快照，开关操作会额外发布状态快照，同一目标分钟可能出现多条记录；保留 seq 和发布运行时间区分状态变化。评估只用成功且目标对齐的预测，同设备、场次、模型、末历史分钟和目标的重复成功快照只计一次，避免重复加权；关闭快照不当作缺失实测或训练标签。

准确度评估用设备、场次、`forecast_target_5_minute` / `forecast_target_15_minute` 对齐后续实际分钟均值。报告各时距 MAE、RMSE、偏差、95% 绝对误差及有效预测比例；未覆盖、历史缺口和模型失败保留并单独统计。不同环境、场次和模型版本分别计算，避免混合造成误导。

## 双情景曲线

延续曲线来自模型，训练数据没有提供风扇动作，所以它不能视为已验证的“不开风扇”反事实。风扇曲线在延续值上应用可配置假设：

```text
fan = baseline − max(0, baseline − 420) × removal
+5 分钟 removal = 0.18
+15 分钟 removal = 0.35
```

参数在 `firmware/config.h`；低于室外参考值时不再扣减。没有实际风量、箱体体积、风扇转速或开孔面积输入，也未闭环驱动风扇。两条虚线只连接当前、+5、+15 三个点，不是每分钟模型输出。后续应用不同风扇档位和开孔实验辨识换气参数，再更新情景模型。

## 通风箱实验与独立候选

计划使用约 40–60 L 透明带盖收纳箱，开孔面积可调；静态实验观察初始高浓度后的响应，动态实验用持续少量释放观察阈值前的预测信号。先保存基线与通风两类独立场次，记录释放起止、开孔位置/面积、风扇状态、传感器位置和时间。

定性展示只能证明系统响应。比较策略效果需要重复工况，并报告超过阈值时长、浓度超限面积、提前量、误报/漏报、风扇运行占比；实际能耗需额外测量，不能以目标档位代替耗电量。

保留的 rapid-rise 候选为历史独立实验：150 场单区质量守恒合成数据，每场 150 分钟，90/30/30 场先划分，再构造窗口。原候选输入为 CO₂/温湿度、网络 60→32→16→2、2,514 参数、int8 4,776 字节；独立配置显式保留三通道，不随当前模型的单变量设置隐式改变。

| 方法 | +5 分钟 MAE | +15 分钟 MAE |
|---|---:|---:|
| 持续性 | 66.68 | 183.65 |
| 岭回归 | 30.82 | 118.99 |
| int8 MLP | 39.24 | 125.25 |

以上为同一量化有效合成测试子集。候选优于持续性、未超过岭回归，尚未替换运行模型。充分混合、泄漏、释放流量、换气和传感器响应均为假设，不能当作实物校准结果。

```powershell
# 复算独立候选的指标，不重新训练当前模型
& ./.venv/Scripts/python.exe model/rapid_rise.py --evaluate-only
```

完整方程与数据来源见 [合成数据说明](../data/rapid-rise/SOURCE.md)，完整指标见 [候选报告](../model/artifacts/rapid-rise/REPORT.md)。运行不带 --evaluate-only 的实验命令会重建合成数据并训练独立候选，使用前应保留已有结果。
