# 系统 System

## 当前能力与边界

当前固件 v1.12.0 使用 ESP32-S3、2.4 英寸横向触摸屏与 SCD41。已实现实时读数、分钟历史、CO₂ TinyML 预测及持久化开关、双情景曲线、触摸校准、环境分类、LittleFS 记录和 USB 导出。

当前运行入口为实时采集，界面没有实测/回放模式切换按钮。保留的回放模块用于已有逻辑检查，不代表系统会在传感器故障时自动改用演示数据。

控制页只预览目标档位；尚未在运行固件中输出 GPIO17 PWM 或读取 GPIO18 TACH。未实现电池电量/充电管理、联网校时、SD 卡存储或实际闭环通风。风扇模拟不证明真实换气效果。

## 数据流程

```text
SCD41 → 约 5 秒原始读数 ───────────→ LittleFS 测量行
       → 一分钟均值 → 连续性检查 → TinyML +5/+15 预测
                                         ├─ 延续 / 风扇模拟曲线
                                         └─ LittleFS 预测快照
故障、恢复、启停、校时、心跳 ─────────→ LittleFS 事件行
LittleFS → USB → 带场次与状态字段的 CSV
```

每分钟至少 8 条成功读数且当分钟没有读取错误，才形成有效均值。连续有效历史达到 20 分钟才推理；无效分钟保留为缺口，不插值。读取错误或 15 秒没有新有效读数时，当前值显示异常；30 秒无有效读数后尝试恢复，每次间隔至少 30 秒。

传感器恢复保留历史和场次。预测失败不删除已保存原始记录，也不把旧实时读数继续显示为有效。

## 显示与触摸

画布为 320×240 RGB565，约 150 KiB；程序按 100 ms 间隔安排重绘。16×16 区域哈希减少静态像素传输，SPI 时钟为 8 MHz。调试页 fps 表示程序重绘次数，不是液晶面板扫描刷新率；不能保证每次完整画面都达到 10 fps。

触摸矩阵包含版本、分辨率、方向和校验和。仅有效矩阵可复用；校准存入独立 NVS 命名空间，不影响 LittleFS 日志。启动校准和设置页入口均保留。

## 时钟与环境

USB 校时保存真实时间与 64 位运行时长锚点；未校时时保留相对时间并允许记录。设备不恢复未知断电间隔。

环境值为 classroom、bedroom、outdoor、enclosed。场次开始时冻结环境，记录中无法切换。所有实时来源统一为 `classroom_measurement`，具体场所由 environment 区分；该 source 名称不意味着每场都在教室。

## 记录协议与可靠性

当前格式为 4，导出兼容格式 1–4。场次头保存设备标识、场次编号、来源、模型哈希、启动运行时长、环境和校时锚点。

| 记录 | 内容 |
|---|---|
| measurement | 每次已解码的新读数、有效状态、错误和当时预测 |
| sensor_fault / 恢复事件 | 通信、CRC、过期、零值、恢复过程等 |
| heartbeat | 每分钟的读数年龄、累计错误、恢复次数、空间与内存 |
| prediction_snapshot | 分钟结算或开关操作时的发布运行时长、末历史分钟、目标分钟、两种情景、状态、模型哈希和模拟参数 |
| minute_summary / prediction_enabled / prediction_disabled | 分钟成功样本数、错误数、失效原因，以及预测开关变化 |
| session_start / session_stop | 场次启停；启动包含复位原因 |
| clock_set / export_begin / export_end | 时间锚点变化与采样暂停边界 |

每条写入后 flush、关闭并检查长度。满盘或写入失败停止写入，不覆盖旧文件、不自动格式化。写入失败信息另存 NVS，下次成功开场时补记。断电可能造成最后一行不完整，导出跳过并报告数量；不能保证正在写入的末行已保存。

记录意图保存于 NVS：记录中重启后新建场次续记，主动停止后不自动开始。USB 导出是同步操作，会暂停采样；导出结束继续原场次，缺口不伪造补齐。

### 容量

当前 16MB 专用分区：NVS 0x9000/0x5000；应用槽 0x10000/0x140000 与 0x150000/0x140000；LittleFS 0x290000/0xD60000，约 13.375 MiB；coredump 0xFF0000/0x10000。实际可写量由文件系统开销和 16 KiB 预留空间共同决定。

原始读数约每 5 秒一条：一天约 17,280 条，两周约 241,920 条。仅按每条 100 字节计算，两周已约 23.1 MiB，超过现有日志分区；预测快照、故障及心跳还会占用空间。因此当前存储不能承诺无管理连续保留两周全部原始数据。长期实验需定期导出和管理容量，或后续增加存储；程序没有自动清理或循环覆盖。

## v1.12.0 验收

v1.12.0 按最终要求保留原双栏主页、原字体、状态胶囊和温度在上/湿度在下的顺序，仅删除顶部标题、时钟与“实测”栏，底部导航保留。设置页显示固件版本并可开关 TinyML；调试分为采样历史、模型性能和存储运行三页。

TinyML 开关保存到独立 NVS 配置，首次默认开启，重启后沿用。关闭立即清空预测并停止推理，继续采样、分钟汇总与原始记录；重新开启复用符合要求的历史。保存失败会显示中文错误并记录英文错误事件，不伪称持久化成功。预测状态 5 表示关闭，旧状态 0–4 不变；CSV 格式 4 支持状态 5，旧格式保持原语义。

Data 提供统一历史诊断；Sensor 在分钟结算时保留成功样本数、错误数与首个失效原因，写入 `minute_summary` 事件。串口 `s` 输出连续有效分钟、首个坏分钟及原因、当前分钟采样数、错误/恢复计数和读数年龄；`p` 与设置页共用预测开关动作。Application 汇集状态到 Interface 诊断快照，页面不直接访问硬件。
